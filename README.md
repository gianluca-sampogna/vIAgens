# vIAgens

Plataforma web que gera roteiros de viagem personalizados com IA.

Projeto acadêmico — Grupo 03.

## Estrutura

| Pasta | O quê | Stack |
|---|---|---|
| `frontend/` | aplicação web | Next.js 16, React 19, Tailwind 4, NextAuth |
| `backend/` | API de autenticação, usuário e roteiros | NestJS, supabase-js, Supabase (Postgres) |
| `docs/` | diagramas UML, specs e planos | — |

Cada pasta tem seu próprio README com instruções de execução.

## Como rodar tudo

Em dois terminais:

```bash
cd backend && yarn install && yarn start:dev     # porta 3333
cd frontend && yarn install && yarn dev          # porta 3000
```
